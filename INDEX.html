Create / Upload Question Paper

The Excel file is uploaded from this computer. Questions are saved in the selected Paper Code sheet of the separate Paper Google Spreadsheet. Re-uploading the same Paper Name replaces that paper only.

Paper Spreadsheet Structure

The Paper Google Spreadsheet contains these seven paper-code sheets:

BASIC · SCREENER(INT) · SCREENER(REC) · INSTRUCTOR · BASIC REFRESHER · INDUCTION · OJT

Each sheet can contain multiple papers. The PaperName column identifies each paper's questions.
